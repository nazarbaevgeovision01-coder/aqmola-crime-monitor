# Aqmola Crime Monitor

Локальный аналитический MVP для работы с агрегированной статистикой. В текущей версии данные хранятся только в браузере; подключение API и БД можно добавить отдельно.

## Запуск

```bash
pnpm install
pnpm dev
```

Либо `npm install` и `npm run dev`, если используете npm.

## Публикация на GitHub Pages

Workflow в `.github/workflows/pages.yml` автоматически собирает сайт и публикует `dist` при push в ветку `main`. Для ссылок на ресурсы используется относительный base path, поэтому подходит и для project pages.

Откройте URL, показанный Vite (обычно `http://localhost:5173`). Для production-сборки: `npm run build`.

## Данные

Стартовый набор синтетический и демонстрационный. Он не является официальной статистикой Акмолинской области. Можно импортировать CSV с колонками `date,region,district,source_type,source_name,category,indicator,value,unit,data_status`; импортируемые строки проверяются, объединяются с демонстрационными и доступны для выгрузки. Все данные остаются на устройстве.

Источники хранятся раздельно (`ROAD_POLICE`, `LOCAL_POLICE`, `AUTOMATED_SYSTEMS`, `OTHER`). Сравнение абсолютных значений описывает зарегистрированные объёмы и само по себе не определяет уровень риска или причины изменений.

Дополнительная аналитика показывает месячную динамику числа строк отдельно по источникам и сравнивает выбранный период с равным по длине непосредственно предшествующим периодом. Красное выделение районов на схеме включается при сумме строго больше 100 для выбранного источника и одного показателя; разные метрики не складываются.

## Архитектура

Первый этап — Vite + React + TypeScript, расчёты и фильтрация вынесены из компонентов, графики построены Recharts, импорт/экспорт работают локально. Следующий этап: FastAPI API со схемами и валидаторами, затем SQLite для прототипа с возможностью перейти на PostgreSQL/PostGIS через слой репозиториев. Frontend будет обращаться к API через сервисный модуль. Карта сейчас схематическая и показывает только агрегаты по районам; точные координаты и персональные данные не поддерживаются.
